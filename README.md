# SYNCIFY Quotation Studio

A static quotation builder for smart home projects. No build step or database is required.

## Use

Open `index.html` in a browser, or deploy this folder to Vercel as an **Other** framework project with no build command. Enter company, client and product details; upload the authentic logo; save a draft; then choose **Download PDF / Print** and **Save as PDF** in the browser print dialog. Turn on background graphics for the full styling if the print dialog offers that option.

Drafts and the uploaded logo are stored in browser localStorage, not synchronized between staff or devices. Use **Export JSON** for backups and **Import JSON** to continue on another device. Do not use shared browsers for sensitive client information. The PDF is generated by the browser's print engine. A future version could add authenticated accounts, server-side storage and direct PDF generation.

The included BOQ sample is transcribed from the supplied Mr Walaa PDF for demonstration. Its line totals are recalculated from quantity × unit price, so it intentionally differs from the arithmetic printed in that PDF. Check all product prices, scope and terms before sending any quote.
